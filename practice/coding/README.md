# Practical TypeScript drills

Each exercise file contains a prompt, concrete example, expected result, signature, and `TODO(PRACTICE)`. The companion test file is marked `it.todo` so the base application stays green. Remove `.todo` one case at a time, implement the exercise, and run `npm run test:practice`.

Reference implementations live in `solutions/`. Avoid opening them until you have a working version and can explain its time/space tradeoffs.

Suggested interview loop: clarify inputs → name edge cases → implement aloud → run tests → discuss production hardening.
